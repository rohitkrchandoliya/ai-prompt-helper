# Accessibility Statement Prompt Examples

A practical prompt template for creating a clear accessibility statement based on supplied information.

## Reusable prompt

> Help me prepare a accessibility statement for the audience and goal described below. Ask about missing essentials, use only supplied facts, label assumptions, organize the result into clear sections, and include next steps.

## Context
- Goal and intended audience
- Relevant background and constraints
- Evidence, source material, or confirmed details
- Preferred format and length
- Timeline and success criteria

## Review checklist
- Is the result specific and useful?
- Are assumptions clearly labeled?
- Are important limitations or risks included?
- Are next steps concrete and verifiable?
