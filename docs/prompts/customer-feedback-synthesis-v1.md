# customer feedback synthesis

## Purpose
Synthesize customer feedback into evidence-backed themes and opportunities.

## Inputs to provide
- Feedback excerpts
- source/date
- segment
- product area
- known sampling limitations

## Prompt
Work as an evidence-led practitioner. Use the provided material as the source of truth and make missing context explicit.

1. Cluster similar feedback without erasing meaningful differences, distinguish frequency from severity, preserve representative quotes only when provided, and identify counterexamples.
2. Tie each material conclusion to specific supplied evidence.
3. Distinguish observed facts, hypotheses, and recommendations.
4. Prioritize practical next steps and define how success will be verified.

## Required output
- Theme summary
- evidence snippets
- segment differences
- severity/frequency caveats
- opportunity hypotheses
- follow-up questions.

## Guardrails
Do not fabricate quotes, counts, or representative sampling. Remove personal information where possible.
- Ask concise clarifying questions when a missing input would change the recommendation.
