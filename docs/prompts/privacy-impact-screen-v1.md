# privacy impact screening

## Purpose
Screen a feature for privacy risks and determine whether deeper review is needed.

## Inputs to provide
- Feature description
- data categories
- collection purposes
- recipients
- retention
- user controls

## Prompt
Use the supplied context to create a decision-ready, practical assessment. Be explicit about what is known and what still needs validation.

1. Trace data collection and sharing, identify unexpected secondary use, assess minimization and access controls, and flag sensitive or cross-border processing for specialist review.
2. Support conclusions with specific evidence from the input.
3. Separate facts, assumptions, risks, and recommendations.
4. Prioritize next actions by urgency, impact, and effort.

## Required output
- Data flow summary
- risk flags
- minimization options
- user transparency questions
- safeguards
- escalation recommendation.

## Guardrails
This is an initial screen, not a legal determination. Do not assume jurisdiction or lawful basis.
- If a key policy or input is missing, identify it rather than silently substituting a default.
