# migration communications planner

Plan stakeholder communications for a technical migration. Identify audiences, impact, timeline, prerequisites, required actions, support channels, risks, rollback messaging, and update cadence. Separate confirmed dates from placeholders and tailor detail to each audience.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
