# exposed secret response

Create a defensive response plan for a suspected exposed credential. Prioritize containment, revocation/rotation, scope assessment, log review, safe evidence preservation, affected-system checks, and prevention. Never reproduce the secret in the output or assume rotation alone resolves exposure.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
