# localization readiness review

Assess product content and UI for localization readiness: externalized strings, pluralization, date/number formats, text expansion, RTL layout, locale fallback, accessibility, and untranslated errors. Provide prioritized tests and distinguish code evidence from assumptions about target locales.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
