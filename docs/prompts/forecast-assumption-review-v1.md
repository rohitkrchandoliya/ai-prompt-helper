# forecast assumption review

Review a forecast and its assumptions. Separate historical facts, model outputs, and judgment calls; test sensitivity to key drivers; identify missing data, dependencies, and downside scenarios; and list monitoring triggers. Do not present projections as guarantees.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
