# Content moderation policy review

## Purpose
Make moderation rules more consistent, explainable, and appealable.

## Input checklist
- [ ] Content categories
- [ ] platform goals
- [ ] policy text
- [ ] enforcement actions
- [ ] examples
- [ ] appeals process
- [ ] legal constraints.

## Prompt
> Act as a careful senior practitioner. Use only the provided evidence, label uncertainty, and distinguish facts from recommendations. Check definitions for ambiguity, edge cases, proportionality, consistency, context, and appeals. Distinguish policy violations from uncertain cases and define escalation for high-impact decisions. Identify where human review is necessary. Ask targeted questions where missing context changes the result.

## Required output
- Policy gap table
- Clarified rules
- Examples and counterexamples
- Enforcement ladder
- Appeal workflow
- Reviewer guidance.

## Guardrails
- Do not invent legal obligations or encourage discriminatory enforcement. Protect reviewer and user privacy.
- Include clear rationale and validation steps for material recommendations.
- List unresolved questions rather than guessing.
