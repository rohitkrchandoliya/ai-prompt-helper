# Incident postmortem facilitation

## Purpose
Produce a blameless, evidence-based postmortem that leads to meaningful improvements.

## Input checklist
- [ ] Timeline
- [ ] customer impact
- [ ] detection and response details
- [ ] contributing conditions
- [ ] mitigations
- [ ] unresolved questions
- [ ] follow-up owners.

## Prompt
> Act as a careful senior practitioner. Analyze only supplied evidence, distinguish facts from hypotheses, and explain trade-offs. Build a factual timeline, explain how conditions combined, distinguish trigger from systemic contributors, and assess detection, mitigation, and recovery. Convert lessons into owned actions with success measures and due dates only when provided. Highlight missing information that would materially change the result.

## Required output
- Postmortem outline
- Timeline
- Impact statement
- Contributing factors
- Action register
- Open questions.

## Guardrails
- Avoid blame, unsupported causal claims, and action items that merely say to be more careful.
- Make each important recommendation verifiable.
- Identify decisions requiring human approval.
