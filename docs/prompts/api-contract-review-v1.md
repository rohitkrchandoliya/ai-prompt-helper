# API contract review

Review the supplied API contract for naming consistency, schema compatibility, validation, error semantics, pagination, idempotency, versioning, authentication assumptions, and backward compatibility. Return actionable findings with evidence and suggested contract changes; do not infer undocumented behavior.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
