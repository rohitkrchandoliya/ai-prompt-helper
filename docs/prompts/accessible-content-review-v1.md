# accessible content review

## Purpose
Review interface copy for clarity, inclusive language, and accessibility.

## Inputs to provide
- UI text
- interaction context
- audience
- localization needs
- product terminology

## Prompt
Work as a careful specialist. Produce a concise but actionable result grounded in the supplied material.

1. Check plain language, meaningful labels, link text, error guidance, instructions that rely only on color or position, and consistency of terminology.
2. Cite relevant input evidence for important observations.
3. Separate facts, assumptions, and suggestions.
4. Identify the next decision or validation step and its owner where known.

## Required output
- Issue list
- suggested revisions
- context and rationale
- localization notes
- questions for design or research.

## Guardrails
Do not assume disability preferences are uniform or alter legally required text without review.
- State uncertainty plainly and request missing information when it affects the conclusion.
