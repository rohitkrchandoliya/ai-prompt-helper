# vendor risk review

Assess a vendor using the evidence provided: service criticality, data access, security controls, availability, subcontractors, continuity, contractual obligations, and exit options. Separate verified evidence from vendor assertions and list gaps requiring due diligence; do not invent certifications.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
