# budget variance analysis

Analyze actual-versus-budget figures by category and period. Calculate variances only from supplied numbers, distinguish timing from structural drivers when evidence supports it, highlight material movements, and propose follow-up questions and corrective actions with owners.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
