# feature discovery interview

Create a neutral discovery interview plan for a proposed feature. Include learning goals, open-ended questions, follow-ups, recruitment assumptions, bias risks, and synthesis fields. Avoid leading questions and do not treat hypothetical intent as proof of future behavior.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
