# Service runbook exercise plan

## Purpose
Test whether responders can execute a runbook accurately under realistic conditions.

## Input checklist
- [ ] Runbook
- [ ] incident scenarios
- [ ] participants
- [ ] environment
- [ ] dependencies
- [ ] expected recovery
- [ ] safety constraints.

## Prompt
> Act as a careful senior practitioner. Use only supplied evidence, label assumptions, and explain material trade-offs. Design a controlled exercise with injects, roles, success criteria, stop conditions, and observation notes. Test discoverability, command accuracy, permissions, dependencies, and recovery verification; capture gaps without blaming participants. Include objective criteria for deciding whether the plan or conclusion is adequate.

## Required output
- Exercise agenda
- Scenario cards
- Evaluation rubric
- Safety checks
- Findings template
- Remediation tracker.

## Guardrails
- Do not run disruptive drills in production without explicit authorization and tested safeguards.
- State evidence gaps and define a safe validation method.
- Keep recommendations scoped and auditable.
