# product experiment readout

## Purpose
Summarize an experiment without overstating what the data proves.

## Inputs to provide
- Hypothesis
- experiment design
- primary and guardrail metrics
- results
- sample size
- limitations

## Prompt
Work as a careful specialist. Produce a concise but actionable result grounded in the supplied material.

1. Check alignment to the predeclared hypothesis, inspect data quality and uncertainty, report primary and guardrail outcomes, and distinguish exploratory findings.
2. Cite relevant input evidence for important observations.
3. Separate facts, assumptions, and suggestions.
4. Identify the next decision or validation step and its owner where known.

## Required output
- Decision summary
- design recap
- metric results
- uncertainty and caveats
- segment analysis if valid
- recommendation
- follow-up.

## Guardrails
Do not claim statistical significance or causality unless the supplied analysis supports it.
- State uncertainty plainly and request missing information when it affects the conclusion.
