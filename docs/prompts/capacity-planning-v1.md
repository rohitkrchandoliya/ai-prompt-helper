# capacity planning worksheet

Build a capacity-planning assessment from workload patterns, growth assumptions, resource metrics, and service objectives. Identify bottlenecks, headroom, uncertainty, scaling options, cost trade-offs, and validation experiments. Label forecasts and never invent measurements.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
