# technical documentation audit

Audit the supplied technical docs for accuracy evidence, completeness, setup reproducibility, outdated instructions, broken conceptual flow, security-sensitive disclosures, and audience fit. Prioritize issues by user impact and provide proposed fixes without claiming to have run commands.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
