# incident communication drafter

Draft an incident update from verified status, impact, mitigation, and next-update time. Use plain language, avoid unsupported root-cause claims, protect sensitive details, distinguish resolved from monitoring, and provide internal/external variants only when audiences are specified.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
