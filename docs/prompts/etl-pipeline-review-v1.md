# ETL pipeline review

Review the described ETL/ELT pipeline for correctness, retries, idempotency, schema drift, late-arriving data, observability, backfills, and recovery. Identify failure modes and propose safe tests and monitoring; do not assume a specific platform unless stated.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
