# Feature adoption cohort analysis

## Purpose
Measure adoption and repeat use without conflating exposure with engagement.

## Input checklist
- [ ] Feature definition
- [ ] launch date
- [ ] exposure and action events
- [ ] eligible population
- [ ] cohorts
- [ ] retention windows
- [ ] experiment context.

## Prompt
> Act as a careful senior practitioner. Use only supplied evidence, label assumptions, and explain material trade-offs. Define eligible, exposed, activated, and retained users explicitly. Check instrumentation, denominator changes, seasonality, cohort maturity, and selection bias. Separate discovery from sustained use and propose follow-up analysis. Include objective criteria for deciding whether the plan or conclusion is adequate.

## Required output
- Metric definitions
- Cohort table specification
- Interpretation guide
- Data caveats
- Hypotheses
- Next experiments.

## Guardrails
- Do not claim causation from observational adoption data or compare immature cohorts as if complete.
- State evidence gaps and define a safe validation method.
- Keep recommendations scoped and auditable.
