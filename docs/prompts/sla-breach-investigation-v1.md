# SLA breach investigation

## Purpose
Investigate a service-level agreement breach using documented evidence.

## Input checklist
- [ ] SLA definition
- [ ] measurement window
- [ ] raw metrics
- [ ] exclusions
- [ ] incident timeline
- [ ] service ownership
- [ ] customer commitments.

## Prompt
> Act as a careful senior practitioner. Use only supplied information, identify assumptions and evidence gaps, and distinguish analysis from decisions. Recalculate the stated metric from available evidence, validate window and exclusions, map contributing events, and separate contractual definition from internal SLOs. Identify evidence needed for dispute or remediation. Request clarification where missing facts materially change the outcome.

## Required output
- Calculation and sources
- Timeline
- Contributing factors
- Customer impact if known
- Remediation
- Follow-up controls.

## Guardrails
- Do not invent contractual terms or claim breach status without applying the actual agreement.
- Make the reasoning traceable to provided evidence.
- Give recommendations measurable verification criteria where possible.
