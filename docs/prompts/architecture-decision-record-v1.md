# architecture decision record

Create an architecture decision record from the context, options, constraints, and quality attributes provided. Include status, context, options considered, decision, rationale, consequences, risks, and revisit triggers. Separate facts from assumptions and identify unresolved questions.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
