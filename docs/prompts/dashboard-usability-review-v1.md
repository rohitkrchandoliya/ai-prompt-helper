# dashboard usability review

Review the dashboard description or screenshots for audience fit, hierarchy, metric definitions, comparisons, filters, accessibility, stale-data indicators, and misleading scales. Recommend prioritized improvements and explain the user question each change helps answer.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
