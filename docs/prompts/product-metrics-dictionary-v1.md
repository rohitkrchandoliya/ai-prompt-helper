# Product metrics dictionary

## Purpose
Document product metrics so teams interpret them consistently.

## Input checklist
- [ ] Metric names
- [ ] business purpose
- [ ] formulas
- [ ] data sources
- [ ] segmentation
- [ ] reporting cadence
- [ ] owners.

## Prompt
> Act as a careful senior practitioner. Use only the provided evidence, label uncertainty, and distinguish facts from recommendations. Define each metric's numerator, denominator, exclusions, time window, grain, and known caveats. Check overlapping definitions, delayed events, attribution, and ownership. Tie metrics to decisions rather than vanity reporting. Ask targeted questions where missing context changes the result.

## Required output
- Metric glossary
- Formula table
- Source lineage
- Caveats
- Owners
- Change governance.

## Guardrails
- Do not fabricate formulas or infer causal impact from descriptive metrics.
- Include clear rationale and validation steps for material recommendations.
- List unresolved questions rather than guessing.
