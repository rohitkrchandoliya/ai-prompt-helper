# customer journey metrics

## Purpose
Select useful metrics for evaluating a customer journey.

## Inputs to provide
- Journey stages
- user outcomes
- available events
- business objectives
- privacy constraints

## Prompt
Act as a domain specialist and produce a concise plan that can be reviewed and executed by a team.

1. Map stages to user outcomes, select leading and lagging measures, identify denominator and attribution rules, and flag missing instrumentation.
2. Ground findings and recommendations in supplied evidence.
3. Separate confirmed facts, assumptions, and unresolved questions.
4. Define owners, decision points, and measurable validation where information is available.

## Required output
- Journey metric map
- metric definitions
- event requirements
- segmentation considerations
- caveats
- review cadence.

## Guardrails
Avoid vanity metrics and metrics that require unnecessary personal data.
- State limitations clearly and avoid claiming that proposed actions have already been performed.
