# data quality audit

Design a data-quality audit for the provided dataset and business rules. Check completeness, validity, uniqueness, consistency, freshness, referential integrity, and outliers. Provide reproducible checks, thresholds to confirm, sample findings only when evidence exists, and remediation ownership.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
