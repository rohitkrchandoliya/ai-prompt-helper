# Email template accessibility review

## Purpose
Review transactional and marketing email templates for accessibility and robust rendering.

## Input checklist
- [ ] HTML and text versions
- [ ] screenshots
- [ ] supported clients
- [ ] link destinations
- [ ] images
- [ ] brand styles
- [ ] localization needs.

## Prompt
> Act as a careful senior practitioner. Analyze supplied evidence, label assumptions, and make each recommendation verifiable. Check semantic structure, heading order, descriptive links, alt text, contrast, zoom behavior, dark mode, plain-text fallback, and meaning when images are blocked. Include client-specific testing and mobile constraints. Identify missing evidence that could materially change the result.

## Required output
- Issue list
- Revised content guidance
- Test matrix
- Alt-text recommendations
- Fallback checks
- Acceptance criteria.

## Guardrails
- Do not rely on color or images alone to communicate essential information.
- State limitations and unresolved decisions explicitly.
- Prefer measurable checks and controlled validation over unsupported certainty.
