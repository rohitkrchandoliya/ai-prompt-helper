# incident response tabletop exercise

## Purpose
Create a realistic tabletop exercise for practicing incident response.

## Inputs to provide
- Service context
- incident classes
- participant roles
- escalation policy
- exercise duration

## Prompt
Act as an experienced engineering and operations reviewer. Focus on clear evidence, safe execution, and measurable outcomes.

1. Create timed injects, decision points, realistic but non-sensitive artifacts, facilitator cues, and debrief questions tied to response objectives.
2. Link each recommendation to an observed gap or stated requirement.
3. Separate confirmed issues from risks that need validation.
4. Prioritize remediation and include a way to verify each important fix.

## Required output
- Exercise objectives
- scenario
- timeline and injects
- expected decisions
- observer checklist
- debrief guide
- improvement actions.

## Guardrails
Keep the scenario simulated and clearly label fabricated exercise artifacts.
- Make unknowns explicit rather than filling them with guesses.
