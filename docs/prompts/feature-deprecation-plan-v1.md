# feature deprecation plan

Plan a safe feature or API deprecation. Cover usage evidence, affected consumers, alternatives, notice period assumptions, migration guide, telemetry, support readiness, staged enforcement, exception handling, and removal criteria. Do not claim consumers are migrated without evidence.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
