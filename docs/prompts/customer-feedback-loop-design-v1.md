# Customer feedback loop design

## Purpose
Design a closed-loop process from customer feedback to action and communication.

## Input checklist
- [ ] Feedback channels
- [ ] customer segments
- [ ] product teams
- [ ] privacy constraints
- [ ] response commitments
- [ ] existing workflows.

## Prompt
> Act as a careful senior practitioner. Use only the provided evidence, label uncertainty, and distinguish facts from recommendations. Map intake, deduplication, classification, prioritization, ownership, customer follow-up, and trend synthesis. Define how feedback informs decisions without equating volume with importance. Include closure communication and escalation for urgent issues. Ask targeted questions where missing context changes the result.

## Required output
- Workflow
- Taxonomy
- Ownership and SLA proposal
- Prioritization rubric
- Feedback-to-roadmap traceability
- Metrics.

## Guardrails
- Do not promise delivery dates or expose customer identities unnecessarily.
- Include clear rationale and validation steps for material recommendations.
- List unresolved questions rather than guessing.
