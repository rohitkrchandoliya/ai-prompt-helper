# access review campaign

Plan a least-privilege access review using roles, entitlements, owners, and system criticality. Define reviewer guidance, evidence requirements, exception handling, revocation checks, and audit trail. Never recommend removing access without checking ownership and operational dependencies.

## Output requirements

Use only the supplied context. Separate confirmed facts from assumptions and unknowns. Prioritize actionable recommendations, explain rationale and risks, and include validation steps. Never invent evidence or claim checks were run when they were not.
