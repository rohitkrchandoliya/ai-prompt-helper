# user onboarding journey review

## Purpose
Find friction and drop-off risks in a product onboarding journey.

## Inputs to provide
- User segments
- journey steps
- analytics funnel
- support feedback
- success definition

## Prompt
Work as an evidence-led practitioner. Use the provided material as the source of truth and make missing context explicit.

1. Map the journey, identify unclear choices and unnecessary effort, interpret funnel drop-offs cautiously, and suggest testable improvements.
2. Tie each material conclusion to specific supplied evidence.
3. Distinguish observed facts, hypotheses, and recommendations.
4. Prioritize practical next steps and define how success will be verified.

## Required output
- Journey map
- friction points
- evidence
- user impact
- prioritized experiments
- success metrics
- instrumentation gaps.

## Guardrails
Do not infer user intent from analytics alone or treat correlation as proof of a UX cause.
- Ask concise clarifying questions when a missing input would change the recommendation.
