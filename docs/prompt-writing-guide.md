# Practical Prompt-Writing Guide

A useful prompt tells the AI what you want, why you need it, what constraints matter, and what a good answer should look like.

## A five-part prompt structure

1. **Goal:** State the task in one sentence.
2. **Context:** Share the background the assistant needs.
3. **Constraints:** Mention limits, required tools, audience, tone, or exclusions.
4. **Output format:** Ask for a checklist, table, outline, code, or another specific format.
5. **Quality check:** Explain how the result should be evaluated and ask the assistant to flag uncertainty.

## Example

**Vague:** `Help me study biology.`

**Improved:** `Create a 7-day beginner study plan for cell biology. I can study 30 minutes per day. Include one topic, a short active-recall exercise, and a five-question self-test for each day. Keep explanations simple and identify concepts I should review again if I score below 4/5.`

## Before you submit

- Is the goal specific?
- Is the audience or skill level clear?
- Have you supplied relevant context without exposing private information?
- Are the constraints realistic?
- Is the desired output format explicit?
- Can you tell whether the answer is good?

## Iterate instead of starting over

If the result is too broad, ask for a narrower scope. If it is too long, specify a length. If it misses a requirement, name the missing requirement and ask for a revision. Verify important factual claims independently.
