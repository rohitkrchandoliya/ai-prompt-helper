# Release Checklist

Before publishing or announcing a release:

- [ ] Review the changes included in the release.
- [ ] Run `npm test` and resolve failures.
- [ ] Complete the relevant sections of [Manual Testing](manual-testing.md).
- [ ] Verify the main prompt workflow and prompt-history import/export.
- [ ] Check that README instructions and screenshots, if any, match the current app.
- [ ] Confirm no secrets, private data, or temporary debugging files are included.
- [ ] Review known limitations and document any user-visible breaking changes.
- [ ] Confirm the default branch is in the expected state and the release notes are accurate.
