# Troubleshooting

## The page or controls do not respond

1. Confirm JavaScript is enabled for the site.
2. Refresh the page and try again.
3. Open the browser developer console and note any error messages if the problem continues.
4. Check whether a browser extension is blocking scripts.

## Prompt history is missing

- History is stored in the current browser profile and is not automatically shared across devices.
- Check whether the browser allows local storage for the site.
- Private browsing modes or privacy settings may restrict storage.
- Avoid clearing site data until you have exported any prompts you want to keep.

## Import or export does not work

- Confirm the selected file is the expected JSON export from the app.
- Keep a copy of the original file before trying to edit it.
- If import fails, retry with a fresh export and capture the exact error message.

## When reporting a bug

Include your browser and operating system, the steps that reproduce the problem, what you expected, and what happened instead. Remove personal information and secrets from screenshots, exported files, and console logs before sharing them.
