# Privacy and Data Handling

## Prompt history

Prompt history is stored in the browser's local storage for the current site and browser profile. It is not automatically synchronized between browsers or devices. Anyone with access to the same browser profile may be able to access that stored history.

## Exported files

When you export history, the downloaded file may contain the prompts you saved. Store it somewhere appropriate, and delete it when it is no longer needed. Review the file before sharing it.

## Sensitive information

Do not enter passwords, API keys, authentication tokens, financial details, or confidential personal information into prompts. Avoid sharing screenshots, issue reports, or exported history that contain private information.

## Clearing data

Clearing site data or browser storage may permanently remove locally saved history. Export any prompts you want to retain before clearing storage or resetting the browser.
