# Contributing to AI Prompt Helper

Thanks for helping improve AI Prompt Helper. Contributions should make the app more useful, accessible, reliable, or easier to understand.

## Good first contributions

- Improve a confusing instruction or error message.
- Add a useful prompt template with a clear use case.
- Fix a reproducible bug.
- Improve keyboard navigation or accessible labels.
- Add documentation or tests for existing behavior.

## Before opening a pull request

1. Check existing issues and files to avoid duplicating work.
2. Keep the change focused on one user-facing improvement.
3. Explain any non-obvious behavior in code comments or documentation.
4. Test the affected flow manually; add automated tests when practical.
5. Update documentation if setup instructions or behavior change.

## Pull request description

Include the problem, the change and its rationale, how you tested it, and screenshots for relevant visual changes.

## Review expectations

Be respectful and specific in reviews. Prefer small, understandable changes over unrelated edits bundled together. Each pull request should deliver a real project benefit, not just increase contribution counts.
