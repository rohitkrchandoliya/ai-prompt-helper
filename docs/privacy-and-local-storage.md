# Privacy and Browser-Local Prompt History

AI Prompt Helper's prompt-history feature uses browser storage so saved entries can remain available in the same browser profile.

## What browser-local storage means

- Saved entries are associated with the browser profile and site origin on that device.
- Clearing site data or browser storage may remove saved history.
- Private/incognito sessions generally have separate, temporary storage.
- Browser-local storage is not the same as encrypted password storage or a secure vault.

## Protect sensitive information

- Do not save passwords, API keys, access tokens, financial account details, or confidential personal information in prompts.
- Review a prompt before sharing screenshots or exporting history.
- Treat exported JSON and text files as ordinary files that may be copied or synced elsewhere.
- Only import JSON files from sources you trust, and review imported content before using it.

## Clearing history

Use the app's history controls to delete individual entries or clear the saved history when those controls are available. You can also clear site data through your browser settings; this may remove other site preferences too.

## Important limitation

Browser-local storage does not automatically sync history across devices. Anyone with access to the same unlocked browser profile may be able to access stored entries. Avoid entering sensitive data even when history is stored locally.
