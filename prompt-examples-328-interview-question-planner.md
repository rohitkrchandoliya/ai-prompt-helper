# Interview Question Planner

## Prompt

> Help me create a useful interview question planner using the context I provide. Ask for essential missing details, separate facts from assumptions, use clear headings, and provide practical next steps.

## Context to include
- Purpose and audience
- Background and constraints
- Source information
- Preferred format
- Timeline and success measures

## Review
- Is the result clear and specific?
- Are unsupported claims avoided?
- Are next steps actionable?
