# Data Dictionary Prompt Examples

Prompts to document dataset fields with names, definitions, types, allowed values, examples, null handling, source, ownership, and sensitivity classification. Flag ambiguous fields for confirmation.

## Reusable prompt

> Help me create a data dictionary tailored to the context below. First identify missing information and ask concise clarifying questions. Use only the facts I provide, label assumptions, organize the output with clear headings, and finish with actionable next steps.

## Context to provide

- Goal and audience
- Relevant background and constraints
- Available evidence or source material
- Desired format and length
- Deadline, owner, or success criteria (if applicable)

## Quality checklist

- Is the output specific to the supplied context?
- Are facts, assumptions, and unknowns clearly distinguished?
- Are recommendations practical and easy to verify?
- Are privacy, accessibility, and relevant risks considered?
