# Training Session Plan

## Prompt template

> Help me create a training session plan using the context I provide. Ask for missing essentials, present the plan in a clear structure, and include actionable next steps.

## Context
- Goal and audience
- Background and constraints
- Available source material
- Preferred format and timeline

## Quality checklist
- Keep the output specific and practical.
- Mark assumptions and unknowns.
- Avoid unsupported claims.
- Make follow-up actions clear.
