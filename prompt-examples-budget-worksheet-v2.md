# Budget Worksheet

## Prompt template

> Help me prepare a budget worksheet. Use the context below, ask for essential missing details, organize the output in a practical format, and list clear next steps.

## Context
- Purpose and audience
- Background and constraints
- Source information
- Format and deadline

## Checklist
- Be clear and specific.
- Mark assumptions.
- Avoid unsupported details.
- Include actionable next steps.
