# Contributor Code of Conduct

## Our commitment

We want AI Prompt Helper to be a welcoming place for people with different backgrounds, experience levels, and viewpoints. Participation should be respectful, constructive, and focused on improving the project.

## Expected behavior

- Be considerate and respectful in issues, reviews, discussions, and pull requests.
- Explain technical disagreements with evidence and focus on the work, not the person.
- Accept constructive feedback and assume good intent while addressing impact.
- Respect privacy and never post another person's personal information or credentials.

## Unacceptable behavior

Harassment, insults, discriminatory language, threats, deliberate disruption, and sharing private information without permission are not acceptable.

## Reporting and enforcement

Report conduct concerns privately to the repository maintainer through their GitHub profile. Include links or context where possible, but do not publicly expose sensitive information. The maintainer will review reports and may edit or remove content, warn participants, or restrict participation when necessary.

This code applies to project spaces and when someone is representing the project in public.
