# Personal Learning Plan

## Prompt template

> Help me prepare a personal learning plan based on the information provided. Ask for missing essentials, structure the output clearly, and include practical next steps.

## Context fields
- Goal and audience
- Relevant background
- Constraints and source material
- Preferred format and timeline

## Checklist
- Keep it clear and specific.
- Avoid inventing facts.
- Flag unknowns.
- Include actionable next steps.
