# Team Knowledge Sharing Session Prompt Examples

A knowledge sharing session helps colleagues exchange practical expertise, examples, and lessons learned in a format others can reuse.

## Prompt templates

### Plan a session
> Plan a knowledge sharing session about **[topic]** for **[audience]**. The desired outcome is **[outcome]**. Suggest a simple agenda, examples, participant activities, and time for questions.

### Create learning material
> Turn these notes into a concise session outline and reusable reference: **[notes]**. Define unfamiliar terms, preserve important caveats, and identify missing information.

### Capture follow-up
> Summarize the key takeaways, unresolved questions, useful resources, and agreed next steps from these notes: **[notes]**. Do not invent decisions or owners.

## Quality checklist
- Session objective is clear
- Content fits the audience
- Examples are practical
- Unknowns are labeled
- Follow-up is actionable
