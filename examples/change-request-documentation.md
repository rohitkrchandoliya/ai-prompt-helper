# Change Request Documentation Prompt Examples

## Draft a change request
"Draft a change request for [proposed change]. Include current state, requested change, business reason, scope, out-of-scope items, expected benefits, cost and schedule implications, risks, dependencies, and approval needed. Mark unknowns clearly."

## Assess impact
"Assess the likely impact of this proposed change across scope, schedule, budget, quality, security, accessibility, operations, and affected stakeholders. Separate known facts from estimates and list questions needed before approval."

## Compare alternatives
"Compare the requested change with keeping the current approach and with [alternative]. Use agreed criteria, identify trade-offs, and recommend a decision process without fabricating quantitative estimates."
