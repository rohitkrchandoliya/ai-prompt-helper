# cloud cost optimization Prompt Template

Analyze the cloud usage and billing evidence provided to find cost-saving opportunities without undermining reliability or security. Group ideas by estimated savings confidence, effort, risk, and reversibility; distinguish measured costs from estimates; include validation steps, owners, and guardrails. Do not invent prices or recommend deleting resources before ownership and dependencies are verified.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
