# feature flag rollout Prompt Template

Design a controlled feature-flag rollout for the described change. Define cohorts, eligibility, exposure steps, metrics, guardrails, monitoring windows, ownership, kill-switch behavior, accessibility/privacy considerations, and rollback triggers. Include a checklist for verifying server/client default states and stale-flag cleanup. Do not propose collecting unnecessary personal data.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
