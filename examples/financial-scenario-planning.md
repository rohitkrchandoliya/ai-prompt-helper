# Financial Scenario Planning Prompt Examples

## Build scenarios
"Create base, upside, and downside scenarios for [planning question] using only the inputs supplied. List each assumption, formula, time period, and output. Mark unknown inputs rather than inventing them. Inputs: [paste]."

## Stress-test assumptions
"Identify the assumptions with the greatest effect on this forecast. Propose sensitivity tests and explain how to interpret the results. Keep historical actuals separate from projections and label illustrative values clearly. Forecast: [paste]."

## Explain variance
"Compare actual results with budget or forecast. Calculate absolute and percentage variance where data permits, identify plausible drivers supported by evidence, and list follow-up questions. Do not attribute causation without support. Data: [paste]."
