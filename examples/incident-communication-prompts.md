# Incident Communication Prompt Examples

## 1. Draft a status update
> Using only these confirmed facts [facts], draft an incident update for [audience]. Include impact, current status, mitigation, and next update time if known. Label unknowns clearly and avoid speculation.

## 2. Structure a post-incident review
> Organize this incident timeline [timeline] into impact, detection, response, contributing factors, and lessons. Use blameless language and distinguish confirmed causes from hypotheses.

## 3. Track follow-up actions
> Convert these review findings [findings] into actionable tasks with an owner role, measurable completion criteria, and priority. Leave owners or dates unspecified when not provided.
