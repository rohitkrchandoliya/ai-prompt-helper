# Customer Journey Workshop Prompt Examples

## Plan a journey workshop
"Design a workshop to map the customer journey for [service]. Include participant roles, research evidence to bring, stages, goals, emotions if evidenced, pain points, backstage dependencies, and desired outputs. Avoid treating assumptions as validated insights."

## Facilitate journey mapping
"Create neutral facilitation questions for each journey stage: trigger, user goal, actions, touchpoints, friction, workarounds, and outcome. Include prompts to surface exceptions and accessibility needs without leading participants."

## Turn findings into experiments
"Convert the journey-map findings into a set of testable improvement hypotheses. For each, state supporting evidence, expected user benefit, experiment, success measure, and uncertainty. Do not present hypotheses as confirmed causes."
