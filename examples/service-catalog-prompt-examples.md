# Service Catalog Entry Prompt Examples

Service catalog entries describe offerings, owners, request paths, service levels, and dependencies consistently.

## Prompt templates

### Create
> Create a service catalog entry for **[organization/project]**. Intended reader: **[reader]**. Desired outcome: **[outcome]**. Use supplied information, state assumptions, and identify missing details.

### Audit
> Audit this draft: **[paste draft]**. Check consistency, clarity, evidence, omissions, and practical feasibility. Return prioritized findings and a corrected version.

### Adapt
> Rework this content for **[audience and context]**, emphasizing **[priorities]** and using a **[tone]** tone. Preserve the underlying facts and identify any unresolved decisions. Content: **[paste content]**.

## Quality checklist
- Reader and purpose are explicit
- Key terms are consistent
- Claims are supported or qualified
- Trade-offs and constraints are visible
- Recommended actions are concrete
