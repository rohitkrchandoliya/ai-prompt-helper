# Data Migration Validation Plan Prompt Examples

A data migration validation plan compares source and destination records, rules, exceptions, and sign-off evidence.

## Prompt templates

### Draft
> Draft a data migration validation plan for **[context]**. Audience: **[audience]**. Target result: **[result]**. Respect supplied constraints and note unknown details.

### Critique
> Critique this draft for clarity, sequence, completeness, inclusivity, and practicality: **[draft]**. Prioritize improvements and provide an edited version.

### Apply
> Adapt the revised approach to **[specific situation]**. List actions, role-based responsibilities, dependencies, and checks that confirm the intended result.

## Quality checklist
- Audience and purpose are clear
- Important constraints are considered
- Assumptions are stated
- Actions and responsibilities are explicit
- Success checks are observable
