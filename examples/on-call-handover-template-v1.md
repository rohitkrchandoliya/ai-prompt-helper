# on-call handover Prompt Template

Convert the current operational state into an actionable on-call handover. Summarize active incidents, recent changes, known degradations, key dashboards, alert thresholds, pending mitigations, escalation contacts/roles, and next checkpoints. Separate urgent work from FYIs, include timestamps/time zones, redact credentials and personal data, and do not invent service status.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
