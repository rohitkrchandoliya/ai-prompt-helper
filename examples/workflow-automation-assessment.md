# Workflow Automation Assessment Prompt Examples

## Assess automation suitability
"Assess this workflow for automation suitability using task volume, rule stability, exception rate, data quality, risk, integration effort, and human judgment needs. Distinguish suitable automation candidates from steps that should remain human-reviewed. Workflow: [paste]."

## Map current and future process
"Document the current workflow and propose a future-state version. Show triggers, inputs, decisions, systems, handoffs, exceptions, controls, and human approval points. Mark all inferred steps for confirmation."

## Plan a pilot
"Create a low-risk pilot plan for automating [task]. Include baseline metrics, scope limits, test cases, fallback, monitoring, owner role, and go/no-go criteria. Do not claim time savings until measured."
