# Migration Checklist Prompt Examples

## 1. Assess readiness
> Review this migration scope [scope] and identify prerequisites, dependencies, owners, data risks, and acceptance criteria. Mark unconfirmed assumptions explicitly.

## 2. Plan validation
> Based on these source and target details [details], propose checks for record counts, integrity, permissions, functionality, and user workflows. Include how to record discrepancies.

## 3. Outline rollback considerations
> For this migration plan [plan], identify rollback triggers, decision roles, backup requirements, and recovery checks. Do not imply rollback is safe until dependencies and data-loss risks are confirmed.
