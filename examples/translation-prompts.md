# Translation Prompt Examples

## Translate with context
Translate the following from [source language] to [target language] for [audience and context]: [text]. Preserve meaning, tone, names, numbers, and formatting. Flag ambiguous phrases rather than guessing.

## Keep terminology consistent
Translate [text] using this glossary: [terms]. Keep each preferred translation consistent and list any term that has no direct equivalent.

## Review a translation
Compare the source [source] and translation [translation]. Identify meaning shifts, omissions, unnatural phrasing, and register mismatches. Suggest corrections without rewriting unrelated content.
