# Migration Readiness Prompt Examples

## Assess readiness
"Assess readiness for migrating [system or data]. Review scope, ownership, dependencies, data quality, compatibility, access, testing, cutover, rollback, and support. For each area, list required evidence and unresolved blockers. Context: [paste]."

## Build a cutover plan
"Create a cutover run sheet with task order, dependency, responsible role, verification, communication checkpoint, go/no-go decision, and rollback trigger. Mark all timings and owners that need confirmation."

## Validate after migration
"Create a post-migration validation checklist covering record counts, integrity, permissions, integrations, key workflows, monitoring, and user acceptance. Define measurable pass criteria from the supplied requirements and flag missing baselines."
