# Ebook Marketing Prompt Examples

## Write a product description
Write a clear sales-page description for this ebook: [title and verified contents]. Identify the intended reader, topics covered, and practical value. Do not promise income, results, or credentials not supported by the book.

## Identify reader segments
Suggest reader segments for [ebook topic]. For each segment, explain its likely need and a way to validate demand. Label hypotheses as hypotheses rather than market facts.

## Plan launch content
Create a [duration]-day content plan for launching [ebook]. Include channel, post idea, call to action, and a simple metric. Keep claims accurate and workload realistic.
