# Project Dependency Review Prompt Examples

A dependency review identifies cross-team commitments, timing assumptions, blockers, and fallback options.

## Prompt templates

### Prepare
> Prepare a project dependency review for **[context]**. Audience: **[audience]**. Objective: **[objective]**. Use confirmed details and flag unknowns.

### Assess
> Assess these notes **[material]** for missing actions, unclear ownership, conflicting expectations, and risks. Prioritize issues and suggest corrections.

### Follow through
> Create a follow-up checklist with responsible roles, dependencies, communication steps, and evidence that each action is complete.

## Quality checklist
- Objective and scope are clear
- Facts and assumptions are separated
- Owners and dependencies are explicit
- Risks and open questions are visible
- Completion can be verified
