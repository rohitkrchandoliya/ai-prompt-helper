# User Feedback Triage Prompt Examples

A feedback triage process sorts incoming reports by theme, urgency, impact, and missing context.

## Prompt templates

### Build
> Build a user feedback triage for **[context]**. Audience: **[audience]**. Objective: **[objective]**. Use the supplied material and clearly mark unknowns.

### Analyze
> Analyze this information **[material]**. Identify recurring themes, gaps, constraints, and alternative explanations. Separate observed facts from hypotheses.

### Plan improvements
> Suggest a prioritized improvement plan with role-based owners, dependencies, validation steps, and review checkpoints. Avoid unsupported claims or invented figures.

## Quality checklist
- Objective and scope are clear
- Findings are evidence-based
- Uncertainty is acknowledged
- Actions are specific
- Review criteria are practical
