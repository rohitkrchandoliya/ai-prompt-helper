# Incident Communication Prompt Examples

## Draft an incident update
"Draft an incident update for [audience] using these confirmed facts: [facts]. Include known impact, current response, next update time if provided, and user action if required. Avoid speculation, sensitive operational details, and unsupported recovery estimates."

## Tailor communications
"Adapt this verified incident message for customers, internal teams, and leadership. Preserve the facts and uncertainty, adjust only the level of detail, and identify anything that requires approval before sending. Message: [paste]."

## Prepare a closure summary
"Draft a closure summary using the confirmed timeline, impact, resolution, and follow-up actions. Distinguish completed fixes from planned work and do not claim all users were unaffected unless verified. Notes: [paste]."
