# Planning Prompt Examples

## Make a project plan
Create a plan to achieve [goal] by [deadline]. My available time and resources are [constraints]. Break work into milestones, list dependencies, define a checkable outcome for each milestone, and flag unrealistic assumptions.

## Prioritize tasks
Help prioritize these tasks: [list]. Rank them by impact, urgency, effort, and dependencies. Explain the ranking and identify one task I can safely defer.

## Pre-mortem
Assume this plan failed: [plan]. List plausible causes, early warning signs, preventive actions, and fallback options. Focus on realistic risks rather than remote possibilities.
