# Documentation Audit Prompt Examples

## 1. Check docs against implementation
> Compare this documentation [docs] with this current implementation or specification [source]. List mismatches with evidence and classify them as confirmed, likely, or needing verification.

## 2. Find missing prerequisites
> Review these setup instructions [instructions] for missing tools, permissions, environment assumptions, version requirements, and recovery steps. Do not invent commands not supported by the project.

## 3. Audit links and references
> Review this reference list [links or document] for duplicated, unclear, or potentially outdated references. If live link checking was not performed, label link status as unverified.
