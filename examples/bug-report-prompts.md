# Bug Report Prompt Examples

## Structure a bug report
Turn these observations into a bug report: [observations]. Include summary, environment, steps to reproduce, expected result, actual result, frequency, and sanitized evidence. Do not infer a root cause without evidence.

## Find a minimal reproduction
Help reduce this failure to the smallest reproducible case: [code or steps]. Suggest one controlled change at a time and preserve the original error details.

## Prepare a triage summary
Summarize this bug for triage: [report]. Identify user impact, reproducibility, affected area, missing diagnostics, and safe next steps. Do not include secrets or personal information.
