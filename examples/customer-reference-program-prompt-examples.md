# Customer Reference Program Prompt Examples

A customer reference program coordinates willing customer participation, clear expectations, and respectful follow-up.

## Prompt templates

### Create
> Create a customer reference program for **[context]**. Audience: **[audience]**. Objective: **[objective]**. Use supplied facts and clearly label unknowns.

### Review
> Review this draft or current state: **[material]**. Identify gaps, risks, unclear responsibilities, and unsupported assumptions. Prioritize improvements and return a revised version.

### Follow through
> Turn the recommendations into a practical action list with responsible roles, dependencies, review checkpoints, and observable completion criteria. Leave unknown details as placeholders.

## Quality checklist
- Objective and scope are clear
- Facts and assumptions are distinguished
- Risks and dependencies are documented
- Next steps are actionable
- Completion criteria can be checked
