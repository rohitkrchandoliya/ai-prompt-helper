# User Story Prompt Examples

## 1. Draft user stories
> Using this product context [context], draft user stories from the user's perspective. Keep each story focused on one outcome and distinguish confirmed needs from assumptions.

## 2. Define acceptance criteria
> For this story [story], write observable acceptance criteria including normal use, validation, permissions, and error states. Use testable language and flag unresolved product decisions.

## 3. Find dependencies
> Review these stories [stories] for dependencies, overlap, and unclear ownership. Explain the impact of each dependency and suggest questions for the product team.
