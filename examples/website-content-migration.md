# Website Content Migration Prompt Examples

## Inventory migration content
"Create a content migration inventory for [site or section]. Include source URL, content type, owner, destination, redirect need, review status, and retention decision. Use supplied data only and flag missing owners or destinations."

## Map redirects
"Propose a redirect mapping from these old URLs to new URLs based on content intent and relevance. Flag unmatched pages and ambiguous cases for human review. Do not send unrelated pages to a generic destination. URL list: [paste]."

## Validate migrated content
"Create a post-migration QA checklist covering content completeness, links, metadata, redirects, accessibility, analytics, and important user journeys. Include test evidence and a clear pass/fail criterion for each item."
