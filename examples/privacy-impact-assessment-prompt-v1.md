# privacy impact assessment Prompt Template

Draft a privacy impact assessment from the stated product and data practices. Cover data categories, purpose, lawful basis to be confirmed by counsel, collection minimization, retention, access, sharing, user transparency, deletion, security controls, risks to individuals, and mitigations. Clearly label missing facts and jurisdiction-dependent questions; do not present the draft as legal advice.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
