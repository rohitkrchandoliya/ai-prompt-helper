# Grant Proposal Prompt Examples

## Structure a proposal
Outline a grant proposal for [program] addressing [verified need]. Include goals, activities, beneficiaries, timeline, evaluation, sustainability, and risks. Mark missing evidence rather than inventing statistics.

## Define measurable outcomes
Turn these program goals [goals] into measurable outputs and outcomes. For each, propose a metric, data source, collection frequency, and limitation. Distinguish outputs from long-term impact.

## Explain a budget
Draft a budget narrative from these verified line items [items]. Explain how each cost supports the program and flag unclear assumptions. Do not create costs or commitments that were not supplied.
