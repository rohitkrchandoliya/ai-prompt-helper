# Data Visualization Brief Prompt Examples

## Write a chart brief
"Recommend a chart for communicating [question] to [audience] using the supplied data. State the comparison or pattern to emphasize, required fields, units, time range, caveats, and accessibility considerations. Do not infer values not present in the data."

## Review a visualization
"Review this chart description or image for misleading scales, unclear labels, missing units, poor comparisons, excessive decoration, and accessibility issues. Explain the likely reader impact and suggest corrections. Chart: [paste]."

## Create a narrative
"Write a concise narrative for this visualization. State the main supported observation, relevant comparison, limitation, and next question. Avoid implying causation from correlation or treating small differences as meaningful without context. Data and chart: [paste]."
