# Product Requirements Document Prompt Examples

## Draft a PRD
"Draft a product requirements document for [problem or feature]. Include problem statement, target users, goals, non-goals, user scenarios, functional requirements, constraints, success measures, dependencies, risks, and open questions. Label assumptions and avoid inventing user research."

## Improve requirement quality
"Review these requirements for ambiguity, testability, duplication, conflicts, and missing acceptance conditions. Rewrite only where meaning is clear and list questions where stakeholder input is needed. Requirements: [paste]."

## Define success measures
"Propose measurable success and guardrail metrics for [feature]. For each metric, explain its definition, data source needed, measurement window, and possible unintended incentives. Distinguish leading indicators from outcomes."
