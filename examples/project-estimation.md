# Project Estimation Prompt Examples

## Break work into estimates
"Break [project or feature] into estimable work packages. For each, list deliverables, dependencies, assumptions, uncertainty, and the roles needed. Provide ranges only when there is a stated basis; otherwise identify information needed to estimate."

## Compare estimation approaches
"Compare [estimation methods] for this team's context, including data needs, benefits, limitations, and risks of false precision. Recommend a lightweight approach and explain how estimates should be calibrated against actuals."

## Explain estimate changes
"Compare the original and updated estimates. Identify which scope, assumptions, dependencies, or risks changed, and separate confirmed drivers from possible explanations. Suggest how to communicate the change clearly. Estimates and notes: [paste]."
