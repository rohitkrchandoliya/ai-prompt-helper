# Learning Prompt Examples

Use these examples as starting points in AI Prompt Helper.

## Explain a difficult topic
Explain [topic] to a beginner using plain language, a step-by-step explanation, and two everyday examples. Define unfamiliar terms and finish with a short recap.

## Practice questions
Create 10 practice questions about [topic], progressing from easy to challenging. Put the answer key after all questions and explain why each answer is correct.

## Revision plan
Build a [number]-day revision plan for [subject] with daily goals, short recall exercises, and one review checkpoint per day. Assume I can study [minutes] minutes daily.
