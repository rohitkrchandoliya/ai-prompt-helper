# User Story Writing Prompt Examples

## Draft a user story
"Write a concise user story for [user type] who needs to [goal]. Include the user value, assumptions, and acceptance criteria that are observable and testable. Avoid prescribing implementation unless it is a real constraint. Context: [details]."

## Improve acceptance criteria
"Review these acceptance criteria for ambiguity, missing edge cases, and unverifiable wording. Rewrite them as clear, testable conditions and list any product decisions that still need an answer. Criteria: [paste]."

## Identify edge cases
"For this feature [description], identify relevant success, validation, permission, empty-state, failure, and recovery scenarios. Prioritize cases by user impact and explain which require product-owner confirmation."
