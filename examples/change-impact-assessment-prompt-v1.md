# Change Impact Assessment Prompt Template

Assess the likely impact of a proposed change across users, services, teams, data flows, integrations, documentation, operations, and compliance obligations. Build an impact matrix with evidence, severity, dependencies, owners, mitigations, and validation steps. Separate confirmed dependencies from assumptions, flag unknowns, and recommend a staged communication and rollout checklist.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings with priorities, rationale, risks, and actionable next steps. Mark claims that require external verification.
