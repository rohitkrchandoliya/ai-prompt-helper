# Course Outline Prompt Examples

## 1. Structure a course
> Propose a course outline for [learners, subject, duration, prerequisites]. Sequence modules logically and state the intended outcome for each module. Flag scope that may not fit the available time.

## 2. Write learning outcomes
> Draft measurable learning outcomes for [module]. Use observable verbs and align each outcome to the content and assessment. Avoid outcomes that cannot reasonably be evaluated.

## 3. Align assessments
> Compare these outcomes [outcomes], lessons [lessons], and assessments [assessments]. Identify gaps or mismatches and suggest changes without adding unsupported requirements.
