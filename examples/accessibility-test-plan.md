# Accessibility Test Plan Prompt Examples

## Plan an accessibility review
"Create an accessibility test plan for [product or flow]. Cover keyboard navigation, focus visibility and order, labels, headings, contrast, zoom/reflow, error handling, screen-reader behavior, and reduced motion where relevant. Identify applicable standards and the need for human testing."

## Review a user flow
"Review this flow description for potential accessibility barriers. For each issue, describe the affected interaction, likely impact, how to test it, and a possible remediation. Do not claim compliance based only on a textual description. Flow: [paste]."

## Write a defect report
"Create an actionable accessibility defect report with environment, steps to reproduce, expected and actual behavior, assistive technology if relevant, impact, evidence, and a clear retest condition. Leave unknown details blank rather than inventing them."
