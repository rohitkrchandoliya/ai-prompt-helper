# backup and recovery drill Prompt Template

Plan a safe backup and recovery exercise for the named system. Identify scope and authorization, backup prerequisites, isolated test environment, recovery steps, integrity checks, recovery time and point objectives, evidence capture, abort conditions, and restoration responsibilities. Avoid destructive production actions; flag unknown retention or encryption settings for confirmation.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
