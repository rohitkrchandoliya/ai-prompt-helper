# Content Repurposing Prompt Examples

## Adapt content for a new channel
"Adapt this source content for [channel] and [audience]. Preserve its factual meaning, key caveats, and intended message while changing structure and tone to fit the channel. Do not add unsupported claims. Source content: [paste]."

## Create a content package
"Turn this approved source into a package containing [number] short posts, one newsletter summary, and a short video outline. Give each item a distinct angle, keep facts consistent, and identify any wording that needs review. Source: [paste]."

## Check consistency
"Compare these adapted versions with the source. Flag factual drift, missing caveats, changed numbers, and statements that sound stronger than the original. Recommend corrections without rewriting verified details. Source and versions: [paste]."
