# requirements traceability Prompt Template

Build a requirements traceability matrix from the provided requirements, design notes, tests, and acceptance criteria. Map each requirement to implementation evidence, test coverage, owner, status, and unresolved gap. Flag ambiguous or conflicting requirements for review, preserve source identifiers, and never infer coverage from a test name alone.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
