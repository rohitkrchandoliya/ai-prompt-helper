# User Guide Outline Prompt Examples

## Plan a user guide
"Create a user guide outline for [product or task] and [audience]. Organize it around user goals, prerequisites, step-by-step tasks, expected results, troubleshooting, and further help. Identify gaps where product details are missing."

## Write a task procedure
"Write a task-based procedure for [task] using the supplied steps. Include prerequisites, numbered actions, expected result, and recovery guidance for known errors. Do not invent UI labels or features. Notes: [paste]."

## Review guide usability
"Review this guide for task order, plain language, missing prerequisites, inconsistent terms, and places where screenshots or examples would help. Return prioritized edits and questions for the product owner. Guide: [paste]."
