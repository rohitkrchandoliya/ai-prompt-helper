# accessibility test plan Prompt Template

Build an accessibility test plan for the interface and user journeys described. Include keyboard-only testing, focus order and visibility, semantics and names, contrast, zoom/reflow, forms and errors, screen-reader checks, motion preferences, and assistive-technology coverage. Map each test to an expected result, severity, reproducible steps, and evidence; distinguish automated checks from manual evaluation.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
