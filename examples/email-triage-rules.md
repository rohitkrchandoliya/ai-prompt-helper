# Email Triage Rules Prompt Examples

## Create triage categories
"Design email triage categories for [role or workflow], such as urgent action, scheduled action, waiting, reference, and low priority. Define clear rules and examples for each category. Do not infer urgency from tone alone."

## Summarize a thread
"Summarize this email thread with the main topic, confirmed decisions, open questions, action items, owners if explicitly stated, and deadlines if explicitly stated. Flag conflicting messages and never invent commitments. Thread: [paste]."

## Draft a response plan
"Based on this thread, propose the key points a response should address, the tone, and any facts that need checking before sending. Do not send or imply that a reply has been sent. Thread: [paste]."
