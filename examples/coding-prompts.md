# Coding Prompt Examples

## Debug an error
Help me debug this [language/framework] issue: [error and observed behavior]. First list likely causes, then suggest the smallest safe diagnostic steps. Do not assume files or dependencies I have not shown.

## Review a change
Review the following code for correctness, edge cases, security, readability, and performance. Prioritize actionable findings, explain impact, and suggest focused fixes. Do not report style preferences as bugs.

## Understand a codebase
Explain the purpose and flow of this [language] module for a newcomer. Identify its inputs, outputs, dependencies, and error handling. Separate what the code proves from what needs more context.
