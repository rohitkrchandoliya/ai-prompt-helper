# Travel Itinerary Prompt Examples

## Build an itinerary
Create a realistic itinerary for [destination] over [duration], considering interests, travel pace, budget, and accessibility needs: [details]. Flag details that require current verification.

## Compare routes
Compare these route options by travel time, cost, transfers, and convenience using the supplied information: [options].

## Adjust a plan
