# User Research Screener Prompt Examples

A research screener recruits suitable participants using neutral, relevant criteria and avoids leading questions.

## Review checklist
- Scope and audience are clear
- Terms and assumptions are explicit
- Evidence supports important claims
- Risks and dependencies are addressed
- Output leads to a useful next action
