# Meeting Agenda Prompt Examples

## 1. Create an outcome-focused agenda
> Create a [duration] agenda for [meeting goal and attendees]. For each item, specify desired outcome, timebox, and preparation needed. Separate decisions from information sharing.

## 2. Improve a crowded agenda
> Review this agenda [agenda] against the meeting's goal [goal]. Identify items to defer, combine, or handle asynchronously, and preserve enough time for decisions and questions.

## 3. Offer an async alternative
> Turn this meeting purpose [purpose] into an asynchronous workflow with context to share, a clear response deadline if supplied, decision owner, and a method for resolving disagreements.
