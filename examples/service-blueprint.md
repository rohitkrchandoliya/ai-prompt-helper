# Service Blueprint Prompt Examples

## Map a service
"Create a service blueprint for [service] from the supplied customer journey. Separate customer actions, frontstage interactions, backstage work, supporting systems, and evidence visible to the customer. Mark assumptions and missing handoffs. Journey: [paste]."

## Find failure points
"Review this service blueprint for delays, duplicate effort, unclear ownership, accessibility barriers, and failure points. For each issue, describe customer impact, likely cause if evidenced, and a way to validate it. Blueprint: [paste]."

## Improve handoffs
"Suggest improvements to the handoffs in this service process. Include responsible role, information required, trigger, expected response time to agree, and fallback when a handoff fails. Do not assume current staffing or system capabilities."
