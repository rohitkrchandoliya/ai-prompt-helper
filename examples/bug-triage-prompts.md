# Bug Triage Prompt Examples

## 1. Triage a report
> Assess this bug report [report] for user impact, reproducibility, affected scope, and missing information. Recommend a tentative priority with reasoning; do not infer severity from labels alone.

## 2. Request missing details
> Identify the minimum additional information needed to reproduce this issue [report]. Draft concise questions about environment, steps, expected behavior, actual behavior, and logs while avoiding secrets.

## 3. Cluster related reports
> Compare these anonymized reports [reports] for likely duplicates. Explain shared symptoms and meaningful differences, and label uncertain matches for human review.
