# Brand Messaging Framework Prompt Examples

## Draft messaging pillars
"Create a draft messaging framework for [organization or product] and [audience]. Include audience needs, value proposition, three messaging pillars, proof points required, and tone guidance. Clearly label assumptions and do not invent customer results."

## Adapt messaging by audience
"Adapt this approved message for [audience or channel] while preserving its factual claims and core positioning. Explain changes in emphasis and flag any new claims that need approval. Source message: [paste]."

## Check message consistency
"Compare these materials against the approved messaging framework. Flag inconsistent terminology, unsupported promises, unclear differentiation, and tone mismatches. Suggest focused edits. Materials and framework: [paste]."
