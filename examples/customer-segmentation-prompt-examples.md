# Customer Segmentation Strategy Prompt Examples

Customer segmentation groups audiences using defensible needs and behavior signals while noting data limitations.

## Prompt templates

### Draft the artifact
> Develop a customer segmentation strategy for **[context]**. Intended users: **[audience]**. Desired result: **[result]**. Use the supplied information, identify unknowns, and organize recommendations in a practical format.

### Review the draft
> Review **[draft]** for accuracy, clarity, coverage, and real-world usability. Highlight unsupported claims, missing steps, risks, and confusing language. Then produce an improved version.

### Build an execution plan
> Create an execution plan from this approved draft: **[draft]**. Include stages, responsible roles, dependencies, evidence of completion, and feedback checkpoints. Mark all unresolved details as open questions.

## Checklist
- Clear audience and purpose
- Evidence-backed, qualified claims
- Risks and constraints surfaced
- Actionable steps and responsibilities
- Review and success criteria included
