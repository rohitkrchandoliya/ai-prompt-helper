# support escalation brief Prompt Template

Prepare a concise escalation brief from the support ticket and investigation notes. Include customer impact, reproducible steps, expected versus actual behavior, environment, timeline, sanitized evidence, attempted workarounds, severity rationale, and exact ask for the receiving team. Remove credentials and unnecessary personal data; mark unverified details.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
