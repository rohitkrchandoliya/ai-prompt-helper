# Learning Assessment Prompt Examples

## Create an assessment
"Create an assessment for these learning outcomes: [outcomes]. Include a mix of question types where appropriate, clear instructions, answer key, and scoring rubric. Ensure every item measures a stated outcome and avoid irrelevant trick questions."

## Check assessment fairness
"Review these assessment items for ambiguity, accessibility, cultural assumptions, reading burden, and alignment with learning objectives. Suggest revisions and explain what each item is intended to measure. Items: [paste]."

## Give formative feedback
"Provide formative feedback on this learner response using the supplied rubric. Identify demonstrated strengths, the highest-priority improvement, and one practical next step. Do not infer motivation or ability from a single response. Response and rubric: [paste]."
