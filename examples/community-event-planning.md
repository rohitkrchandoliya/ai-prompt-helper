# Community Event Planning Prompt Examples

## Create an event plan
"Plan a [type of event] for [audience] with [goal] and [constraints]. Include timeline, venue needs, accessibility, staffing roles, registration, communications, safety considerations, contingency plans, and a realistic budget template. Flag details requiring local confirmation."

## Coordinate volunteers
"Create a volunteer run sheet with task, time, owner role, supplies, briefing notes, escalation contact, and completion check. Include setup, arrival, event delivery, cleanup, and post-event follow-up. Do not invent named contacts."

## Evaluate outcomes
"Design a post-event evaluation using attendance, participation, accessibility feedback, goal achievement, costs, and lessons learned. Distinguish measurable results from anecdotes and suggest improvements for the next event."
