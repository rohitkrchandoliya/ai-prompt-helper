# Digital Service Journey Review Prompt Examples

A digital service journey review examines task completion, friction, accessibility, and user feedback across key steps.

## Prompt templates

### Prepare
> Prepare a digital service journey review for **[context]**. Audience: **[audience]**. Objective: **[objective]**. Use supplied facts, note uncertainties, and define the scope.

### Evaluate
> Evaluate this draft or evidence: **[material]**. Identify strengths, gaps, consistency issues, and risks. Explain which conclusions are well-supported and which need more evidence.

### Improve
> Recommend prioritized improvements and a practical implementation plan with role-based ownership, dependencies, and observable checks.

## Quality checklist
- Objective and scope are explicit
- Criteria are applied consistently
- Evidence supports conclusions
- Risks and limitations are noted
- Improvements are actionable
