# threat model workshop Prompt Template

Facilitate a defensive threat-model workshop for the described application. Identify assets, trust boundaries, entry points, data flows, plausible abuse cases, likelihood/impact assumptions, existing controls, and prioritized mitigations. Use a structured table and include residual risk and validation steps. Stay at authorized defensive analysis; do not provide exploit instructions against real targets.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
