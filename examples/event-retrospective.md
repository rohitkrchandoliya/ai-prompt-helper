# Event Retrospective Prompt Examples

## Facilitate a retrospective
"Create a retrospective agenda for [event or project]. Include intended outcomes, what worked, what did not, evidence, contributing conditions, and improvements. Use a blame-free tone and invite different perspectives."

## Synthesize lessons
"Summarize these retrospective notes into strengths to preserve, problems to address, root-cause hypotheses, and lessons learned. Separate direct observations from interpretations and note conflicting viewpoints. Notes: [paste]."

## Create improvement actions
"Turn the lessons into a small set of prioritized actions. For each, include the issue addressed, owner role, completion evidence, and review date to agree. Avoid vague actions such as 'communicate better' without a concrete behavior."
