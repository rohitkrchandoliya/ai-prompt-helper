# performance benchmark planning Prompt Template

Create a repeatable performance benchmark plan for the target workload. Specify environment parity, dataset shape, warm-up, repetitions, baseline, latency percentiles, throughput, resource metrics, load profiles, noise controls, acceptance thresholds, and reporting. Explain how to avoid comparing unlike runs and define a regression investigation path; never fabricate benchmark results.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
