# Resume Prompt Examples

## Improve a resume bullet
Rewrite this real experience as a concise resume bullet: [experience]. Preserve the facts, do not invent metrics, and ask what measurable result is missing if useful.

## Match a job description
Compare my resume [resume] with this role [description]. List supported matches, gaps, and keywords I can truthfully use. Do not add skills or qualifications I have not provided.

## Summarize experience
Create a short professional summary for [target role] using only these verified skills and experiences: [details]. Avoid generic claims and unsupported years of experience.
