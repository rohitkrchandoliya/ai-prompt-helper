# incident postmortem Prompt Template

Create a blameless incident postmortem from the timeline, customer impact, alerts, mitigations, and follow-up notes provided. Structure it as summary, impact, timeline with timezone, detection, contributing factors, what worked, what did not, corrective actions with owners and due dates, and verification signals. Distinguish established facts from unknowns; avoid assigning personal blame.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
