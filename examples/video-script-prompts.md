# Short-Form Video Prompt Examples

## Draft a short video script
Write a [duration]-second video about [topic] for [audience]. Break it into timed beats, include a strong but truthful opening hook, visual directions, and a clear ending. Respect these production constraints: [constraints].

## Build a visual storyboard
Turn this script into a shot list: [script]. For each shot, specify duration, subject, camera movement, on-screen text, and transition. Avoid adding visuals that contradict the narration.

## Create captions
Write concise captions and on-screen text for [video]. Keep text readable on mobile, provide captions for spoken content, and do not rely on sound alone to convey essential information.
