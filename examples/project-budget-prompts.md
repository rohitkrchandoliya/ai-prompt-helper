# Project Budget Prompt Examples

## 1. Draft a budget structure
> Create a budget template for [project] with likely cost categories, units, quantity assumptions, and calculation notes. Leave amounts blank when no reliable estimates are supplied.

## 2. Review assumptions
> Review these budget figures and assumptions [data]. Check arithmetic, missing categories, double counting, and unclear estimates. Separate calculation errors from uncertain forecasts.

## 3. Compare scenarios
> Compare these scenarios [scenario data] using the same cost categories and timeframe. Show key drivers, trade-offs, and sensitivities without presenting estimates as guaranteed outcomes.
