# Procurement Evaluation Prompt Examples

## Build evaluation criteria
"Create a vendor evaluation matrix for [purchase]. Include required capabilities, total cost considerations, security, accessibility, support, implementation effort, exit terms, and evidence needed. Separate mandatory requirements from weighted preferences."

## Compare vendor proposals
"Compare these proposals using the agreed criteria. Cite the supplied section or page for each material claim, identify missing or non-comparable information, and do not assume a lower price means lower total cost. Proposals: [paste]."

## Prepare due-diligence questions
"Generate vendor due-diligence questions based on these proposal gaps. Prioritize questions that could change the decision, affect risk, or alter total cost. Label questions for legal, security, finance, or technical reviewers where appropriate."
