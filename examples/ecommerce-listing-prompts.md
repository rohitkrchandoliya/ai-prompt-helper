# Ecommerce Listing Prompt Examples

## 1. Write a product description
> Using only these product facts [facts], write a clear description for [audience]. Highlight verified benefits, avoid unsupported performance claims, and identify missing specifications.

## 2. Structure a listing
> Organize these attributes [attributes] into a readable product listing with title, key features, specifications, and care or usage notes where supplied. Do not fill gaps with assumptions.

## 3. Check listing consistency
> Compare these product details [sources]. Flag conflicting dimensions, materials, compatibility, or included items. Recommend which details need confirmation before publication.
