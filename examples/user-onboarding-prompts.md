# User Onboarding Prompt Examples

## 1. Design a first-run flow
> Design a minimal onboarding flow for [product] and [audience]. Identify the user's first meaningful outcome, optional steps, accessibility needs, and privacy-sensitive data to avoid collecting.

## 2. Write helpful empty states
> Draft concise empty-state copy for [screen and context]. Explain what the user can do next, use a clear action, and avoid blame or unsupported promises.

## 3. Find onboarding friction
> Review this onboarding flow [steps/screens]. Identify confusing terms, unnecessary decisions, accessibility barriers, and places users may abandon. Separate evidence from hypotheses and suggest measurable improvements.
