# Service Observability Review Prompt Template

Review the available service telemetry and operational objectives. Map critical user journeys to useful metrics, logs, traces, service-level indicators, alert thresholds, dashboard views, and ownership. Identify noisy or missing signals, sampling/retention concerns, and actionable gaps. Separate observed telemetry from proposed instrumentation, and include validation steps and alert-tuning safeguards.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
