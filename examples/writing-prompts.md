# Writing Prompt Examples

## Draft from notes
Turn these notes into a clear [format] for [audience]: [notes]. Preserve the intended meaning, do not invent facts, and mark any missing details with concise questions.

## Improve a draft
Edit the following text for clarity, flow, grammar, and concision: [draft]. Preserve my voice and meaning. Return the revised version first, then list only the most important changes.

## Adjust tone
Rewrite this message in a [friendly/formal/confident/empathetic] tone for [recipient]. Keep the key facts and request unchanged, avoid exaggerated claims, and keep it under [word count] words.
