# Project Risk Register Prompt Examples

## 1. Identify project risks
> Using this project context [context], identify plausible risks across delivery, people, technology, dependencies, and operations. For each, describe a cause, possible impact, early warning signal, and uncertainty.

## 2. Suggest mitigations
> Review these risks [risk list] and propose proportionate mitigations, contingency actions, and an accountable role. Do not assume budget, authority, or resources that have not been confirmed.

## 3. Review risk changes
> Compare these risk updates [previous and current status]. Highlight risks that increased, decreased, or need new evidence. Distinguish changed facts from changed estimates.
