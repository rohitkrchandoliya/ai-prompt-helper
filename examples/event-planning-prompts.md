# Event Planning Prompt Examples

## 1. Build a run of show
> Create a run-of-show for [event, date, duration, sessions]. Include time, activity, responsible role, required materials, and transition notes. Mark missing venue or timing details as questions.

## 2. Create a logistics checklist
> Build a checklist for [event type and size] covering venue, accessibility, registration, equipment, communications, and cleanup. Distinguish essential tasks from optional enhancements.

## 3. Plan contingencies
> For this event plan [plan], identify plausible risks and practical contingencies. Include a trigger, responsible role, and fallback action for each, without assuming resources that are not available.
