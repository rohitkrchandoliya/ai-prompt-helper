# Quality Assurance Test Case Prompt Examples

## Generate test cases
"Generate test cases for [feature] from these requirements. Include ID, preconditions, steps, expected result, priority, and linked requirement. Cover positive, negative, boundary, permission, and recovery cases. Do not invent behavior where requirements are unclear."

## Review test coverage
"Map these test cases to the requirements and identify untested behaviors, duplicate tests, unclear expected results, and gaps in failure handling. Separate confirmed coverage gaps from cases needing clarification. Requirements and tests: [paste]."

## Create regression checklist
"Create a focused regression checklist for [change]. Prioritize affected workflows, integrations, permissions, data migration, and user-visible behavior. Include test environment needs and explicit exit criteria. Change summary: [paste]."
