# technical debt prioritization Prompt Template

Prioritize the listed technical debt items using impact, frequency, change risk, maintenance cost, security implications, and remediation effort. State scoring criteria and confidence, group quick wins versus strategic work, and connect each recommendation to evidence. Include defer conditions and revisit triggers; do not invent engineering-hour estimates when none are available.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
