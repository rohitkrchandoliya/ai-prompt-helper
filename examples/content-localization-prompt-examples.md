# Content Localization Brief Prompt Examples

Localization briefs account for audience context, cultural nuance, terminology, formatting, and review requirements.

## Prompt templates

### Draft
> Create a content localization brief for **[context]**. Audience: **[audience]**. Objective: **[objective]**. Use only supplied facts, flag unknowns, and structure the output into practical steps, responsibilities, and completion criteria.

### Review
> Review this draft: **[paste draft]**. Find omissions, ambiguity, unsupported assumptions, and risks. Prioritize fixes and return an improved version without inventing facts.

### Tailor
> Adapt this material for **[audience/region/use case]**. Preserve the intended outcome, explain necessary changes, and list any approvals or open questions. Material: **[paste material]**.

## Quality checklist
- Clear objective and scope
- Audience and constraints stated
- Evidence separated from assumptions
- Risks and dependencies identified
- Actionable next steps and completion criteria
