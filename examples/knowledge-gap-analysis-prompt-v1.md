# knowledge gap analysis Prompt Template

Compare the current documentation or team's stated knowledge with target tasks and observed support questions. Identify specific gaps, affected audiences, evidence, risk, and prioritized learning assets. Recommend owners, formats, review cadence, and a measurable validation method. Separate documented absence from proof that nobody knows the topic.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
