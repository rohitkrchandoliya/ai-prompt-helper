# Customer Advocacy Program Prompt Examples

A customer advocacy program identifies willing advocates, aligns participation with their interests, and tracks mutual value.

## Prompt templates

### Draft
> Create a customer advocacy program for **[context]**. Audience: **[audience]**. Goal: **[goal]**. Use provided facts, label assumptions, and identify missing information.

### Review
> Review this draft or process: **[material]**. Find gaps, inconsistencies, unclear ownership, and risks. Rank improvements and return an actionable revised version.

### Implement
> Translate the recommendations into steps with responsible roles, dependencies, review points, and observable completion criteria. Leave unknown details as placeholders.

## Quality checklist
- Scope and purpose are clear
- Ownership and decision rights are explicit
- Assumptions and limitations are visible
- Recommendations are practical
- Review and follow-up are defined
