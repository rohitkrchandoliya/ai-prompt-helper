# Product Design Prompt Examples

## Map a user journey
Map the journey for [user] trying to [goal]. Include steps, questions, friction points, accessibility considerations, and opportunities to validate assumptions.

## Compare design options
Compare these approaches to [problem]: [options]. Evaluate usability, implementation effort, accessibility, privacy, and maintainability. State which unknowns need user research.

## Plan a usability test
Create a moderated usability test for [prototype] and [target users]. Write neutral tasks, success signals, follow-up questions, and consent/privacy notes. Avoid leading participants.
