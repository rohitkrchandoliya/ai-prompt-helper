# Grant Application Outline Prompt Examples

## Map requirements
"Turn these grant guidelines into a compliance checklist. Capture eligibility, required sections, page or word limits, attachments, deadlines, evaluation criteria, and submission method. Quote or reference the supplied guideline section for each item and flag ambiguities. Guidelines: [paste]."

## Draft a proposal outline
"Create a grant proposal outline for [project] aligned to the stated evaluation criteria. Include problem statement, target population, activities, outcomes, evaluation, timeline, budget rationale, and sustainability. Mark missing facts and do not invent impact statistics. Project details: [paste]."

## Review the narrative
"Review this draft against the grant criteria. Identify unsupported claims, unclear outcomes, missing implementation detail, and mismatches with the funder's priorities. Give actionable edits without exaggerating capacity or results. Draft and criteria: [paste]."
