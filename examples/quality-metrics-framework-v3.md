# Quality Metrics Framework Prompt Examples

A quality metrics framework links measurable signals to user outcomes, process risks, and improvement decisions.

## Prompt templates

### Design
> Design a quality metrics framework for **[context]**. Audience: **[audience]**. Intended outcome: **[outcome]**. Use provided information, state assumptions, and flag missing inputs.

### Check
> Check this proposed approach for coverage, consistency, feasibility, bias, and unintended effects: **[draft]**. Rank the main gaps and propose corrections.

### Operationalize
> Turn the recommendations into a short implementation plan with owners by role, dependencies, validation steps, and unresolved questions.

## Quality checklist
- Scope and audience are clear
- Evidence and assumptions are separate
- Risks and limitations are documented
- Actions are specific
- Validation is practical
