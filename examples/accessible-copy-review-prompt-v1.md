# accessible copy review Prompt Template

Review the supplied UI copy for clarity and accessibility. Check plain language, descriptive link and button labels, understandable form instructions, actionable error messages, heading consistency, inclusive wording, localization risks, and avoidance of color-only directions. Provide original text, issue, proposed rewrite, and rationale; preserve product meaning and flag context-dependent recommendations.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
