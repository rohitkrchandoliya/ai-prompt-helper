# Customer Complaint Analysis Prompt Examples

Complaint analysis groups concerns, identifies recurring patterns, and separates observed facts from possible causes.

## Prompt templates

### Create
> Create a customer complaint analysis for **[context]**. Audience: **[audience]**. Objective: **[objective]**. Use supplied details and identify gaps rather than guessing.

### Analyze
> Analyze this source material: **[material]**. Extract themes, conflicts, missing information, and risks. Distinguish direct evidence from interpretation and prioritize findings.

### Recommend
> Based on these findings, propose realistic next steps, responsible roles, dependencies, and verification criteria. Mark unresolved questions clearly.

## Quality checklist
- Objective and scope are defined
- Findings are grounded in evidence
- Uncertainties are labeled
- Recommendations are actionable
- Follow-up criteria are explicit
