# release risk assessment Prompt Template

Assess release risk based on change scope, dependencies, customer impact, migration needs, test evidence, and operational readiness. Score likelihood and impact using explicitly stated criteria, identify risk owners, list go/no-go checks, monitoring signals, staged rollout options, and rollback triggers. Keep assumptions visible and do not turn missing evidence into a positive assurance.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
