# Service Process Documentation Prompt Examples

Service process documentation describes triggers, steps, exceptions, responsibilities, and completion checks.

## Prompt templates

### Draft
> Draft a service process documentation for **[context]**. Audience: **[audience]**. Purpose: **[purpose]**. Use provided details and label unknowns.

### Review
> Review this material **[draft]** for completeness, clarity, consistency, and practical use. Identify missing steps, unclear ownership, risks, and unsupported assumptions.

### Finalize
> Produce a revised version and a concise action checklist. Include role-based responsibilities, dependencies, verification steps, and unresolved questions.

## Quality checklist
- Purpose and scope are explicit
- Steps and terms are consistent
- Exceptions and risks are considered
- Responsibilities are clear
- Completion can be verified
