# Documentation Style Guide Prompt Examples

## Draft a style guide
"Create a documentation style guide for [product or team]. Cover audience, voice, terminology, headings, procedures, links, examples, accessibility, code formatting, and handling of warnings. Use supplied standards and mark unresolved choices."

## Check terminology
"Review these documents for inconsistent names, capitalization, abbreviations, and definitions. Propose a preferred term and list affected passages, preserving technical meaning. Documents: [paste]."

## Apply the style guide
"Edit this documentation to follow the supplied style guide. Preserve factual details and technical behavior, note substantive changes, and flag unclear passages instead of silently guessing. Text and guide: [paste]."
