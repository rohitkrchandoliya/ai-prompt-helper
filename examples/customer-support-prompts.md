# Customer Support Prompt Examples

## Draft a support reply
Write a clear, empathetic reply to this customer issue: [issue]. Acknowledge the impact, provide only verified steps, ask only necessary questions, and avoid promising a resolution or timeline we cannot confirm.

## Troubleshoot step by step
Help diagnose [problem] in a safe sequence. Start with low-risk checks, explain what each result means, and pause before any step that could delete data, expose secrets, or disrupt service.

## Prepare an escalation
Summarize this case for the next support tier: [notes]. Include observed behavior, expected behavior, steps already tried, relevant error messages, and missing information. Remove passwords, tokens, and unnecessary personal data.
