# customer interview synthesis Prompt Template

Synthesize anonymized customer interview notes into themes without overstating representativeness. Separate direct quotes, observed behavior, participant interpretation, and analyst inference; map themes to evidence counts and counterexamples; preserve dissenting views; and list follow-up questions. Avoid sensitive personal details and never invent quotations or participant numbers.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
