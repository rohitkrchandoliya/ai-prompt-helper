# code review checklist Prompt Template

Review the supplied diff against the stated requirements and project conventions. Check correctness, edge cases, error handling, security, privacy, performance, accessibility, maintainability, and test coverage. Report only actionable findings with severity, file/line references from the supplied diff, impact, and a suggested fix. Separate definite bugs from questions and avoid style-only nitpicks unless requested.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
