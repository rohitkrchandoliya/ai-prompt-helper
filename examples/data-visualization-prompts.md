# Data Visualization Prompt Examples

## 1. Choose a chart type
> Recommend a chart for this dataset and question [data/question]. Explain why the encoding fits, what comparisons it supports, and what information may be obscured.

## 2. Review chart clarity
> Review this chart description or image [chart] for axis labels, units, scale, color meaning, accessibility, and misleading visual emphasis. Separate definite problems from items that need the source data.

## 3. Write a chart caption
> Write a concise caption for this chart using these values and context [data/context]. Describe the main pattern without implying causality or extrapolating beyond the shown range.
