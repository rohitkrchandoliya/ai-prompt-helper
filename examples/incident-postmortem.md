# Incident Postmortem Prompt Examples

## Build a blameless timeline
"Organize these incident notes into a timestamped timeline with confirmed events, user impact, detection, response actions, and recovery. Mark uncertain timestamps and gaps. Avoid assigning blame or inventing causes. Notes: [paste]."

## Explore contributing factors
"Based on the confirmed timeline, list possible contributing factors and the evidence needed to validate each. Separate root causes, contributing conditions, and hypotheses. Focus on system improvements rather than individual fault."

## Create follow-up actions
"Turn these postmortem findings into prioritized actions. For each, include the risk addressed, a measurable completion condition, suggested owner role, dependency, and target timeframe to be agreed by the team. Findings: [paste]."
