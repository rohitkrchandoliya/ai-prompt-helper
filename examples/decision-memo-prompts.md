# Decision Memo Prompt Examples

## Compare options for a decision
Help evaluate [decision] using these options [options] and criteria [criteria]. Summarize benefits, costs, risks, reversibility, and unknowns. Explain any weighting assumptions and avoid false precision.

## Record a recommendation
Draft a decision memo from these facts [facts]. Include context, recommendation, alternatives, rationale, risks, and next steps. Separate verified facts from estimates and opinions.

## Set review triggers
For this decision [decision], propose measurable signals and dates that should trigger a review. Include what evidence would support continuing, adjusting, or reversing the decision.
