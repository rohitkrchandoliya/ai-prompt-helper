# SQL Query Prompt Examples

## 1. Draft a query from a schema
> Using this schema [schema] and question [question], draft a SQL query and explain joins, filters, grouping, and assumptions. Ask for clarification if the meaning of a field is unclear.

## 2. Explain an existing query
> Explain this SQL [query] step by step, including joins, filters, aggregation, and possible duplicate-row behavior. Do not claim the query was run.

## 3. Review query efficiency
> Review this query and schema [query/schema] for potential performance concerns. Suggest how to inspect the query plan and index options, but distinguish hypotheses from measured bottlenecks.
