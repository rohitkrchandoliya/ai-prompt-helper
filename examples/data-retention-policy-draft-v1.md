# data retention policy drafting Prompt Template

Draft a data retention schedule from the stated data categories, purposes, operational needs, and jurisdiction. For each category, propose a retention rationale, deletion/archive process, legal-hold exception to be confirmed, owner, and audit evidence. Flag legal and regulatory questions for qualified review; do not invent mandatory periods or imply the draft is approved policy.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
