# Accessible Content Prompt Examples

## 1. Rewrite in plain language
> Rewrite this content [text] for [audience] using clear language and short sentences. Preserve all essential meaning, explain necessary jargon, and list any ambiguity rather than guessing.

## 2. Improve link text
> Review these links in context [content]. Suggest descriptive link text that makes sense out of context and distinguishes links with different destinations. Do not alter the actual destinations.

## 3. Review inclusive language
> Review this content [text] for unnecessary assumptions, stigmatizing language, and avoidable barriers. Explain each concern with context and offer alternatives without changing the author's intended meaning.
