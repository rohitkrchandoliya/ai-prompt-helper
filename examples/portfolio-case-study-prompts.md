# Portfolio Case Study Prompt Examples

## 1. Structure a case study
> Turn these project notes [notes] into a case study outline with context, problem, role, constraints, process, outcome, and lessons. Do not claim work or results that are not in the notes.

## 2. Explain personal contribution
> Help distinguish my direct contribution from team contributions using these details [details]. Ask for clarification where ownership is unclear and avoid overstating responsibility.

## 3. Present outcomes responsibly
> Use these verified results [results] to write a concise outcome section. Explain the baseline and measurement context where supplied, and identify claims that need evidence before publication.
