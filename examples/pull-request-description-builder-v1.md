# pull request description Prompt Template

Turn the change summary, linked issue, implementation notes, tests, and screenshots into a concise pull request description. Include problem, solution, scope, user impact, testing performed, risks, rollout/rollback notes, and reviewer focus areas. Never state tests passed or behavior was verified unless that evidence is supplied; preserve links and mark unknowns clearly.

## Reusable instruction

Use only the context provided. Ask clarifying questions when missing information changes the recommendation; otherwise state assumptions. Present findings in a structured format with priorities, rationale, risks, and actionable next steps. Mark any claim that requires external verification.
