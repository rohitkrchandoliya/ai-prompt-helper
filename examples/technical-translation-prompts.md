# Technical Translation Prompt Examples

## 1. Translate technical content
> Translate this technical text [text] from [source language] to [target language] for [audience]. Preserve identifiers, code, units, warnings, and meaning. Flag ambiguous terms instead of guessing.

## 2. Maintain terminology
> Build a glossary from this source [text] with source term, proposed translation, context, and confidence. Keep product names and identifiers unchanged unless instructions say otherwise.

## 3. Review a translation
> Compare the source [source] and translation [translation]. Flag omissions, changed numbers, inconsistent terms, and formatting issues. Do not rewrite content that is already accurate without reason.
