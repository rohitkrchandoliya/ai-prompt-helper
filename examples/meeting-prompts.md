# Meeting Prompt Examples

## Summarize meeting notes
Summarize these notes for [audience]: [notes]. Separate key discussion points, explicit decisions, open questions, and action items. Do not invent agreement or attribute statements without evidence.

## Extract action items
From this transcript or note set [text], extract action, owner, due date, and dependency. Use “not specified” when the source does not name an owner or date.

## Create a decision log entry
Convert this decision record [details] into a concise log with context, options considered, decision, rationale, owner, date, and review trigger. Mark missing fields clearly.
