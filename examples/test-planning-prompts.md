# Test Planning Prompt Examples

## 1. Build a risk-based test plan
> For this feature [requirements], list the highest-risk behaviors, test scenarios, expected outcomes, and prerequisites. Include happy paths, invalid inputs, boundaries, and failure modes.

## 2. Find edge cases
> Analyze this function or workflow [description/code] and identify boundary conditions, state transitions, malformed inputs, and concurrency or timing risks where relevant. Explain why each case matters.

## 3. Select regression tests
> Given this change [diff/summary] and existing tests [list], recommend targeted regression tests. Map each test to a plausible failure and identify coverage gaps without claiming tests were executed.
