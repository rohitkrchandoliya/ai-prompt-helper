# Customer Communication Review Prompt Examples

A customer communication review checks that messages are accurate, clear, relevant, accessible, and consistent with the intended next step.

## Prompt templates

### Review a message
> Review this customer message **[message]** for clarity, accuracy, tone, accessibility, and completeness. Identify ambiguous wording and unsupported claims.

### Rewrite for the audience
> Rewrite the message for **[audience]** and **[purpose]**. Preserve confirmed facts, use plain language, and make the next step clear. Do not invent details.

### Check readiness
> Create a brief pre-send checklist covering audience, factual accuracy, links or instructions, timing, ownership, and support contact details.

## Quality checklist
- Audience and purpose are clear
- Claims are verified
- Language is accessible
- Next step is explicit
- Unknown details remain placeholders
