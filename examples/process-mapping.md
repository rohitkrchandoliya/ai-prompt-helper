# Process Mapping Prompt Examples

## Map a current process
"Convert these process notes into ordered steps with trigger, actor role, input, activity, decision, output, handoff, and exception path. Identify gaps and conflicting descriptions rather than guessing. Notes: [paste]."

## Identify process bottlenecks
"Review this process map for rework, queues, duplicated entry, unclear ownership, avoidable approvals, and failure points. For each concern, describe evidence needed and a possible improvement to test. Map: [paste]."

## Design a future process
"Propose a future-state process that addresses the confirmed problems while preserving required controls. Include changed steps, accountable roles, exception handling, validation measures, and transition questions. Process and constraints: [paste]."
