# Bug Report Prompt Examples

Prompts for turning a problem description into a reproducible bug report with environment, steps to reproduce, expected versus actual behavior, severity rationale, logs to collect, and acceptance criteria.

## Reusable prompt

> Help me create a bug report tailored to the context below. First identify missing information and ask concise clarifying questions. Use only the facts I provide, label assumptions, organize the output with clear headings, and finish with actionable next steps.

## Context to provide

- Goal and audience
- Relevant background and constraints
- Available evidence or source material
- Desired format and length
- Deadline, owner, or success criteria (if applicable)

## Quality checklist

- Is the output specific to the supplied context?
- Are facts, assumptions, and unknowns clearly distinguished?
- Are recommendations practical and easy to verify?
- Are privacy, accessibility, and relevant risks considered?
