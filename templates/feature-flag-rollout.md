# Feature Flag Rollout

Roll out a feature gradually and safely.

## Prompt

Create a staged rollout plan for the supplied feature. Include cohorts, guardrail metrics, monitoring, rollback triggers, support readiness, and decision checkpoints. Use explicit thresholds only when provided.

## Output requirements
- Organize the result into useful headings or a table
- Separate supplied facts from assumptions
- Call out missing information and actionable next steps
