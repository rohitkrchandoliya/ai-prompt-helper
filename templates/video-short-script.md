# Short Video Script

Write a concise short-form video script.

## Prompt

Create a short-form video script for the supplied audience and topic. Break it into timed scenes, specify visual action and on-screen text, and match the requested voice or no-voice format. Avoid unsupported claims and copyrighted imitation.

## Output requirements
- Use clear sections and actionable recommendations
- Distinguish supplied facts from assumptions
- Identify missing information rather than inventing it
