# Code Review Checklist

Review code for maintainability and correctness.

## Prompt

Review supplied code against correctness, readability, edge cases, error handling, security, performance, and testability. Cite specific lines or snippets where possible and prioritize findings by impact. Do not invent behavior outside the provided context.

## Output requirements
- Use clear sections and practical recommendations
- Distinguish supplied facts from assumptions
- Flag missing information rather than inventing it
