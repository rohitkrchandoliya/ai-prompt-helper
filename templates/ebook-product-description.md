# Ebook Product Description

Write a clear ebook listing.

## Prompt

Draft an ebook listing from supplied title, contents, audience, and benefits. Include a clear summary, who it is for, key topics, and a non-misleading call to action. Do not invent credentials, contents, or guarantees.

## Output requirements
- Use clear sections and actionable recommendations
- Distinguish supplied facts from assumptions
- Identify missing information rather than inventing it
