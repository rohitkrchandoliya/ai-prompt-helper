# FAQ Builder

Build a useful FAQ.

## Copyable prompt

> Create an FAQ for [product/service/topic] for [audience]. Group questions by theme, answer in plain language, flag answers that require confirmation, and avoid inventing policies, prices, or guarantees.

## Customize it

Replace bracketed placeholders with accurate context before use. Do not include passwords, API keys, or confidential information. Review important outputs before relying on them.
