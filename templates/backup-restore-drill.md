# Backup and Restore Drill

Plan a recovery rehearsal.

## Prompt

Create a backup-and-restore rehearsal plan covering scope, prerequisites, backup verification, restore steps, data integrity checks, recovery objectives, rollback, and evidence to record. Do not assume backup capability exists unless stated.

## Output requirements
- Organize the result into useful headings or a table
- Separate supplied facts from assumptions
- Call out missing information and actionable next steps
