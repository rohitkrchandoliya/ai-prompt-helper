# Social Media Calendar

Build a manageable social content calendar.

## Prompt

Create a social media calendar from the supplied goals, platforms, and cadence. For each post include date placeholder, format, audience, key message, CTA, and asset needs. Mark dates as placeholders if not provided.

## Output requirements
- Organize the result into useful headings or a table
- Separate supplied facts from assumptions
- Call out missing information and actionable next steps
