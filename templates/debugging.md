# Debugging

Debug a problem systematically.

## Copyable prompt

> Help debug this problem: [error and symptoms]. Environment: [language, version, OS]. Expected behavior: [expected]. Actual behavior: [actual]. First suggest safe diagnostic steps, then explain the likely cause and a minimal fix. Do not invent test results.

## Customize it

Replace each bracketed placeholder with accurate details before using the prompt. Remove any section that does not fit your task, and avoid sharing passwords, API keys, or confidential information.
