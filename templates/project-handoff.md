# Project Handoff

Create a clear handoff note for a project or task.

## Copyable prompt

> Prepare a handoff for [project/task] for [recipient/team]. Summarize the goal, current status, completed work, open items, important decisions, dependencies, risks, key links or files, and the next recommended actions. Identify the owner and due date for each action only when provided. Mark unknowns clearly and exclude secrets or unnecessary personal data.

## Customize it

Replace bracketed placeholders with accurate information. Confirm owners, dates, and links before sharing the handoff.
