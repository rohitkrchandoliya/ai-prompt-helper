# Observability Plan

Plan useful system monitoring.

## Prompt

Propose an observability plan for the described service. Identify important user journeys, metrics, logs, traces, alert conditions, dashboards, and ownership. Avoid arbitrary thresholds; state what baseline data is needed.

## Output requirements
- Organize the result into useful headings or a table
- Separate supplied facts from assumptions
- Call out missing information and actionable next steps
