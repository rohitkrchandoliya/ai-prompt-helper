# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through GitHub's **Report a vulnerability** feature on this repository, if it is enabled. If that option is unavailable, contact the repository maintainer privately through their GitHub profile and ask for a secure reporting channel.

Please do not publish exploit instructions or sensitive details in a public issue before the maintainer has had a chance to investigate.

## What to include

- A concise description of the affected behavior
- Steps to reproduce using a local or test environment
- The potential impact
- A suggested mitigation, if you have one

Do not include passwords, API keys, private user data, or other secrets in a report. Please allow reasonable time for investigation and a fix before public disclosure.

## Scope

This policy applies to the AI Prompt Helper repository and its maintained code. Do not test against systems or accounts you do not own or have explicit permission to assess.
