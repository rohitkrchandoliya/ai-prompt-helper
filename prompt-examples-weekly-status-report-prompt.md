# Weekly Status Report

## Prompt

> Create a weekly status report from the context I provide. Ask for essential missing information, structure the result with clear headings, distinguish facts from assumptions, and end with next steps.

## Context to supply
- Goal and audience
- Background and source material
- Constraints and format
- Timing or success criteria

## Quality checks
- Keep it concise and useful.
- Do not invent missing facts.
- Highlight open questions.
- Make next actions clear.
